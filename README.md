# BeadsCraft CRM

**BeadsCraft CRM** — інформаційна система для керування схемами, матеріалами, складськими залишками, замовленнями та виробничими завданнями у сфері бісероплетіння.

Проєкт реалізовано як вебзастосунок на Django з додатковою інтеграцією Telegram-бота.

## Мета проєкту

Метою BeadsCraft CRM є автоматизація основних процесів, пов'язаних із виготовленням виробів із бісеру:

- зберігання та пошук схем;
- облік матеріалів;
- контроль складських залишків;
- фіксація надходжень і списань;
- визначення нестачі матеріалів;
- формування замовлень;
- ведення виробничих завдань;
- отримання інформації через Telegram-бот.

## Основні можливості

### Бібліотека схем

Система дозволяє:

- створювати та редагувати схеми;
- переглядати каталог схем;
- виконувати пошук і фільтрацію;
- додавати матеріали, необхідні для конкретної схеми;
- використовувати статуси доступності схем;
- працювати з обраними схемами.

### Матеріали та склад

Реалізовано:

- каталог матеріалів;
- пошук за назвою, типом, виробником, артикулом і кольором;
- персональний облік складських залишків;
- мінімальний рівень запасу;
- автоматичне визначення малого запасу;
- надходження матеріалів;
- списання матеріалів;
- журнал руху матеріалів;
- контроль доступної кількості перед списанням.

### Замовлення

Модуль замовлень використовується для:

- формування кошика;
- додавання необхідних матеріалів;
- оформлення замовлення;
- перегляду створених замовлень.

### Виробництво

У системі передбачено:

- створення виробничих завдань;
- вибір схеми для виробництва;
- контроль необхідних матеріалів;
- облік використання матеріалів;
- зміну статусів виробничих завдань;
- збереження історії виробництва.

### Панель керування

Головна сторінка містить узагальнену інформацію про роботу системи та забезпечує швидкий перехід між основними модулями.

### Telegram-бот

До проєкту інтегровано Telegram-бот на базі **aiogram**.

Telegram-бот підтримує:

- реєстрацію користувачів;
- рольову модель доступу;
- головне меню;
- перегляд схем;
- пошук схем;
- роботу з матеріалами;
- пошук матеріалів;
- перегляд замовлень;
- роботу з виробництвом;
- перегляд статистики.

Передбачено ролі:

- користувач;
- менеджер;
- адміністратор.

Telegram-профіль може бути пов'язаний з обліковим записом користувача Django.
