# BeadsCraft CRM

Інформаційна система для керування схемами, матеріалами,
замовленнями та виробничими завданнями у сфері бісероплетіння.

## Ідея проєкту

BeadsCraft CRM призначена для зберігання схем виробів,
обліку матеріалів, контролю залишків, формування замовлень
і ведення виробничих завдань.

## Реалізовано

- бібліотеку схем;
- пошук і фільтрацію схем;
- облік матеріалів і залишків;
- журнал надходжень та списань;
- перевірку наявності матеріалів;
- формування замовлень;
- виробничі завдання;
- головну панель зі статистикою;
- спільну навігацію між модулями.

## Технології

- Python;
- Django;
- SQLite;
- HTML;
- CSS.
